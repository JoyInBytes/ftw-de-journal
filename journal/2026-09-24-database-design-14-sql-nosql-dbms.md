# SQL and NoSQL DBMS

A **DBMS** creates, stores, updates, and controls access to databases.

## SQL / relational DBMS

Uses tables, rows, columns, and relationships. Good for structured data, stable schemas, transactions, and strong consistency.

Examples: PostgreSQL, SQL Server, and Oracle.

## NoSQL DBMS

Uses flexible structures for rapidly changing or growing data.

Common types:

- Key-value: Redis
- Document: MongoDB
- Wide-column: Cassandra
- Graph: Neo4j

**Key takeaway:** Choose SQL for structured and consistent transactional data; choose NoSQL for flexible, rapidly growing, or highly connected data.
