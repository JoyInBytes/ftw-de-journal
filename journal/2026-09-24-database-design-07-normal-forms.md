# 1NF, 2NF, and 3NF

- **1NF:** Each cell contains one value and each row is unique.
- **2NF:** The table is in 1NF and every non-key column depends on the whole key.
- **3NF:** The table is in 2NF and non-key columns do not depend on other non-key columns.

## Memory trick

- 1NF: One value
- 2NF: Whole key
- 3NF: Nothing but the key

Normalization helps prevent update, insertion, and deletion anomalies.
