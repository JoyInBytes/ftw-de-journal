# Data Integration

Data integration combines data from different sources into one reliable and usable view.

A pipeline may need to handle:

- Different formats and data types
- Transformations
- Different update frequencies
- Automated tests and alerts
- Security and masking
- Data lineage

Example: combining sales data from PostgreSQL with product data from MongoDB to support marketing decisions.

**Key takeaway:** A reliable integration pipeline makes data consistent, secure, traceable, and useful.
