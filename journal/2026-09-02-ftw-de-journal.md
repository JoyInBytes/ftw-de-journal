# Project - FTW Data Engineering Journal

- **Snapshot:** 2026-09-02
- **Status:** Ongoing
- **Repository:** [JoyInBytes/ftw-de-journal](https://github.com/JoyInBytes/ftw-de-journal)

## In one sentence

A central, beginner-friendly journal for documenting every project with short facts, evidence, lessons, and next steps.

## What I built

- A single project index in the README.
- One concise documentation page for every current repository and featured project.
- A reusable project template for future work.
- Honest status labels for live, completed, in-progress, planned, and empty work.

## Tools and skills

- Markdown, Git, GitHub, documentation structure, and project reflection.

## What I learned

- Consistent short entries make a portfolio easier to scan and maintain.
- Planned work should be labeled clearly instead of presented as finished.
- Private projects can be summarized safely without publishing private source files.

- [ ] Add or update one journal entry whenever a project reaches a meaningful milestone.
