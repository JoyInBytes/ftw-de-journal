# ETL and ELT

## ETL

Extract → Transform → Load

Data is cleaned and reshaped before entering storage. This is common when data must follow a warehouse schema.

## ELT

Extract → Load → Transform

Data is stored first in its original form, then transformed for different uses. This is common with data lakes and big-data platforms.

**Key takeaway:** ETL transforms before storage; ELT transforms after storage.
