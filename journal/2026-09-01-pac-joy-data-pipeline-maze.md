# Project - Pac-Joy: Data Pipeline Maze

- **Snapshot:** 2026-09-01
- **Status:** Live
- **Demo:** [Play Pac-Joy](https://pac-joy-data-maze.ceejaybalansay23.chatgpt.site)

## In one sentence

An interactive learning game that guides players from raw data to business insights through Data Engineering and SQL challenges.

## What I built

- Nine challenges across Easy, Average, and Challenge levels.
- A pipeline journey covering raw data, transformation, validation, and insights.
- Live score tracking and a professional Top 4 leaderboard.
- A mobile-friendly project card connected to my GitHub profile.

## Tools and skills

- SQL concepts, ETL/ELT thinking, data quality, pipeline design, interface design, and project documentation.

## What I learned

- A playful interface can still communicate real technical value.
- GitHub README limitations are easier to handle by linking to a deployed application and using supported image assets.
