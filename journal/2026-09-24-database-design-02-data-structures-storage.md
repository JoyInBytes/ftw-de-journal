# Data Structures and Storage

- **Structured:** Organized tables with a defined schema.
- **Semi-structured:** Some organization without a strict table schema, such as JSON and XML.
- **Unstructured:** Raw files such as images, videos, audio, and text.

- **Data warehouse:** Cleaned, organized storage for analytics.
- **Data lake:** Large-scale storage for data in its original form.
- **Schema-on-write:** Define the schema before loading.
- **Schema-on-read:** Apply the schema when reading.

**Key takeaway:** Warehouses prioritize organized analytics; lakes prioritize flexibility and scale.
