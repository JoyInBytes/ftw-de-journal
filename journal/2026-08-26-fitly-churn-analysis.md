# Project - Fit.ly Churn Analysis

- **Snapshot:** 2026-08-26
- **Status:** Analysis and documentation complete
- **Source:** Private GitHub repository

## In one sentence

A customer-churn analysis that combines account, support, and engagement data to identify risk patterns and recommend practical retention actions.

## What I built

- A repeatable Python analysis with field-level validation and cleaning.
- Exploratory analysis of churn by plan, activity, and support experience.
- Three clear visuals, a written report, and a leadership presentation outline.
- An At-Risk Active Customer Rate KPI with a documented baseline.

## Tools and skills

- Python, data validation, exploratory analysis, KPI design, visualization, business analysis, and technical reporting.

## What I learned

- Inactivity and slow support resolution are strong actionable churn signals in this dataset.
- Findings should be described as associations unless the analysis proves causation.
- Recommendations are stronger when each one connects to a measurable KPI.
