## What I learned

CI/CD means continuous integration and continuous delivery or deployment. It helps teams check changes regularly and prepare or release them through repeatable steps.

For example, a GitHub check can confirm that required files exist before a change is accepted. It only checks the rules we actually configure.

dbt helps turn source data into useful tables through models, which describe how to transform data. Tests and explanations can be kept with those models.

| Layer | Simple purpose |
| --- | --- |
| Bronze | Keep incoming data close to its original form. |
| Silver | Clean data and make formats consistent. |
| Gold | Prepare tables that answer business questions. |
