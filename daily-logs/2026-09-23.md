## What I learned

Data quality means the data is suitable for the job it needs to do. Accuracy means it agrees with a trusted source. Timeliness means it is available when it is needed.

In SQL, a join connects related rows. `GROUP BY` puts rows into groups for calculations. `HAVING` filters those grouped results.

Python and Pandas can turn JSON records into a table, check numeric values, and keep rows that meet a condition. JSON is a common format for exchanging data between programs.

| Chart | What it helps show |
| --- | --- |
| Histogram | How values are spread across ranges. |
| Scatterplot | How two numeric values relate to each other. |
| Box plot | The middle and spread of values, including possible unusual values. |
| Line chart | How a value changes over an ordered sequence, often time. |
