## What I learned

`SELECT` chooses columns. `WHERE` keeps rows that meet a condition. `JOIN` combines related tables. `GROUP BY` puts rows into groups so I can calculate a result for each group.

For example, to find sales by store, I need to know which table contains sales, how each sale connects to a store, and whether the join repeats any sales.

An `INNER JOIN` keeps matching rows. A `LEFT JOIN` keeps all rows from the left table, even when there is no match. Either join can produce extra rows if a row matches several records.

Clear group discussions help us agree on table names, tasks, and expected results.
