## What I learned

An API is a way for one program to request data from another service. Web scraping collects information from a webpage. They are different ways to get source data.

VS Code is where I can edit the code on my computer. GitHub keeps a shared history of the project files. Databricks can run the data-processing work.

Before moving between these tools, I need to confirm which project and branch I am using. Otherwise, I might edit or run the wrong copy.
