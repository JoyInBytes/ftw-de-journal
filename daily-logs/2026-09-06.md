## What I learned

| Area | What I use it for |
| --- | --- |
| Workspace | Organize notebooks and project files. A notebook contains code and notes. |
| Catalog Explorer | Find data objects. A catalog contains schemas, and a schema contains objects such as tables and views. |
| Compute | Provide the resources that run code and queries. |
| Workflows / Jobs | Set up tasks, schedule runs, and check results. |
| Git folders | Work with project files connected to a Git repository, such as one hosted on GitHub. |

This helps me separate where I keep code, where I find data, and what runs the code.

## Problem and solution

**Problem:** I confused the place where data is organized with the place where code runs.

**Solution:** I gave each area a simple purpose: Workspace for files, Catalog Explorer for data, Compute for running code, and Jobs for running tasks automatically.
