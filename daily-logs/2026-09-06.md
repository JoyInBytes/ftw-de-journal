## 💡 What I Learned

- The **Workspace** is where notebooks, folders, and project files are organized.
- **Catalog Explorer** is used to browse and manage data objects such as catalogs, schemas, tables, and views.
- **Compute** provides the processing resources needed to run code and queries.
- **Workflows** is where jobs can be scheduled and monitored.
- A Databricks Git folder helps keep notebook work connected to a GitHub repository.

## ⚠️ Challenge and Fix

- **Challenge:** The interface has many sections, so it was easy to confuse where data is stored versus where code is run.
- **Fix:** Used a simple mental model: Catalog Explorer for data, Workspace for code, Compute for processing, and Workflows for automation.

## ✅ Key Assumptions

- The workspace has the required access to the project catalog and schemas.
- A compatible compute resource is available before running notebooks.
- Git integration follows the repository branch and permission rules.
