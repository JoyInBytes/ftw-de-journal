## What I learned

Delta Lake helps make table updates reliable. Transactions group changes into a controlled operation. Schema enforcement checks that incoming data fits the table's expected structure. Time travel lets me read an older table version while the required history and files are available.

Unity Catalog organizes access rules for data. It helps control who can use different data objects.

Change data capture, or CDC, means identifying changes such as new, updated, or deleted records so a pipeline can process them.

CI/CD helps check and prepare code changes. Databricks jobs run processing tasks. Explaining each part in my notes helps me remember its purpose.
