## What I learned

Great Expectations, often shortened to GX, is a tool for checking whether data follows defined rules.

A setup guide explains how to use the tool. The actual notebooks, groups of checks called suites, and Databricks job tasks still need to be built and connected.

A Python syntax check can find code that Python cannot parse. It does not prove that the code produces the right data.

Clear notes help reviewers see what the pull request includes and what work remains.
