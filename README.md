## Documentation Format

Every project entry answers five questions:

1. What is the project?
2. What did I build?
3. What tools and skills did I use?
4. What did I learn?
5. What will I do next?

Private repositories are summarized without copying raw data or private source files.

## Add the Next Project

1. Copy [templates/project.md](templates/project.md).
2. Save it in the `journal/` folder.
3. Keep the notes short and factual.
4. Commit and push the update.

```bash
git add .
git commit -m "docs: add project journal entry"
git push
```

## Folder Guide

- `journal/` - project snapshots and learning entries
- `daily-logs/` - daily learning and progress notes
- `templates/` - reusable journal templates
- `assets/` - optional images

For a quick study note, use [templates/entry.md](templates/entry.md). For a project, use [templates/project.md](templates/project.md).
